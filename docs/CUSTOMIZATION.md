# Community Customization

Managers open `/rules manage` and use **Community branding** to configure a server-specific display name, accent color, and logo. The branding appears on the Discord verification panel, private holder-role manager, and wallet verification page.

Community logos and currency images are stored inside the community's D1 database. PNG, JPEG, GIF, and WebP are accepted. General logos can be up to 1 MB; currency images can be up to 512 KB. File signatures are validated and SVG is intentionally excluded from browser rendering.

Accent colors automatically choose light or dark button text for readability. Each Discord server keeps independent branding and reward settings.

The Discord application's account name and avatar remain deployment-wide because Discord owns those application properties. Server-specific panels and web flows use the community branding automatically.
